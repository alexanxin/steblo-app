# Erase is permanent and beats later edits

Delete only hides a person: their details still travel in syncs and backups. For a living relative who asks to be removed, there is Erase. It can't be undone. Every device, the erasing one included, keeps only an erased mark for that person, discards every other value for the record, even one set later, and scrubs the person from its history.

This breaks the usual later-wins rule on purpose. A relative who edits the person concurrently must not bring the details back.

Because everyone is an equal editor (ADR 0003), Erase asks for confirmation twice over: the person erasing must type the given name, and a phone receiving an erase by sync lists who it affects and can refuse for now.

Erase cannot reach copies already saved in backups or GEDCOM files, or phones that never sync again, and its confirmation says so.
